“房间大概 12 平方米”还不是订购数量。一份可靠的 Tile take-off 必须包括真正贴砖的每个平面、已选排版、切割与破损余量、每箱覆盖量、批次资料，以及业主有意识保留的维修备用砖。

下面的工作表适合前期预算和与 Supplier 沟通。最终订单不可退换前，应由负责施工的 Installer 或 Contractor 根据现场尺寸和 Set-out 再确认一次。

## 第一步：把每个贴砖平面单独画出来

给每个地面和墙面一个编号，例如主地面 F1、浴室柜墙 W1、淋浴墙 W2。每一面先记录自己的宽、高和结束线，不要一开始就把所有墙合成总数。

在草图上标出：

- 全高和半高贴砖的分界；
- 确实不贴砖的门、窗和其他洞口；
- 需要贴砖的窗边、Nib wall、浴缸台和踢脚；
- Niche、台面、柱子和转折面；
- 不同瓷砖、颜色、尺寸或图案的分界；
- 会影响排版的固定柜体和洁具。

这样可以避免一种常见错误：减掉窗洞，却忘了四周窗边仍要贴砖；或者淋浴尺寸和门口做法还没确定，就先按旧地面订砖。

## 第二步：计算净平方米

全部使用米作为单位。

矩形公式：

> **面积（m²）= 长度（m）× 宽度或高度（m）**

L 形地面可以拆成互不重叠的矩形再相加。有较大不贴砖洞口的墙面，先算整墙，减去洞口，再加回要贴砖的侧边。

墙面示例：

| 项目 | 计算 | 面积 |
| --- | ---: | ---: |
| 整面墙 | 3.20 m × 2.40 m | 7.68 m² |
| 门洞 | 0.82 m × 2.04 m | −1.67 m² |
| 门洞顶部贴砖边 | 0.82 m × 0.10 m | +0.08 m² |
| 两侧贴砖边 | 2 × 2.04 m × 0.10 m | +0.41 m² |
| **净贴砖面积** |  | **6.50 m²** |

条件允许时应测量完成后的实际尺寸。图纸适合早期讨论，但龙骨、板材、Screed 和柜体完成后，真正贴砖面积可能变化。

## 第三步：决定哪些小位置不应该扣除

不是每一个障碍物都能省下一整块砖。小水管、Floor waste 或插座仍需要周围瓷砖，而且会增加切割风险。把每个小物件都扣掉，反而可能低估数量，也让表格无法复核。

实用做法是只扣除确定不贴砖的大面积，再让切割余量覆盖小穿孔和边角废料。以下特殊情况应和 Installer 确认：

- 独立浴缸下面是否继续铺砖；
- 浴室柜或厨房柜在贴砖前还是贴砖后安装；
- Shower base、Linear drain 和 Floor waste；
- 需要整砖对缝的检修口；
- 贴砖 Niche 和包管；
- 位置可能变化的后续柜体。

## 第四步：根据排版设置切割余量

不存在适合所有工程的固定损耗率。澳洲零售商 Calculator 通常给直铺较低余量，对斜铺、Herringbone 或复杂图案给更高余量。Australian Tile Council 也说明，图案复杂或砖难切时应提高余量。

让 Installer 或 Supplier 看过以下内容后确定本项目余量：

- 瓷砖尺寸与房间尺寸、最窄位置的关系；
- 直铺、斜铺、Brick、Herringbone 或模块排版；
- 转角、Niche、穿孔和外露边数量；
- 图案砖或 Book-match 产品的方向与重复；
- 脆性、挑色或缺陷会减少多少可用砖；
- 一边的 Offcut 能否用于另一边；
- 业主希望留下多少完整备用砖。

把百分比和原因写在一起。“12%：直铺但淋浴切口较多”可以复核；“多买一点”不能。

## 第五步：加余量后，再按整箱向上取整

使用两个独立公式：

> **调整后面积 = 净贴砖面积 ×（1 + 余量百分比）**

> **订购箱数 = 调整后面积 ÷ 每箱覆盖面积，再向上取整箱**

示例：

- 地面净面积：8.64 m²；
- 本例直铺方案约定余量：10%；
- 调整后面积：8.64 × 1.10 = 9.504 m²；
- 产品每箱覆盖：1.44 m²；
- 箱数：9.504 ÷ 1.44 = 6.6，因此订 **7 整箱**；
- 实际到货覆盖量：7 × 1.44 = **10.08 m²**。

本例 10% 不是所有工程的建议值。按整箱取整本身已经产生额外材料，所以应看最终能留下多少完整备用砖，不要再自动叠加一个隐藏百分比。

每箱覆盖量应使用当前产品包装或 Supplier order 上的数字，不能从网上找一款相似砖代替，因为包装可能调整。

## 第六步：不同产品和批次分开计算

不要把不同产品混成一个总数。每种砖、Mosaic、Trim 或特殊件单列一行：

| 产品 | 净面积 | 余量 | 每箱覆盖 | 箱数 | 实际覆盖量 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 主地砖 |  |  |  |  |  |
| 淋浴墙砖 |  |  |  |  |  |
| 特色砖或 Mosaic |  |  |  |  |  |
| 踢脚或 Trim | 按长度 | 按件余量 | 每箱件数 |  |  |

Australian Tile Council 建议检查到货箱子的 Shade 和 Calibre 标记一致。开贴前：

1. 把产品编号、标称尺寸、表面和数量与订单核对；
2. 拍下每一种 Shade、Calibre 和 Batch label；
3. 把一张空箱标签和发票一起保存；
4. 开足够多的箱检查色差和可见缺陷；
5. 标签或产品不一致时停工并联系 Supplier。

不同批次或缺陷砖一旦上墙，后续向 Supplier 处理会困难很多。

## 第七步：单独决定维修备用砖

以后维修的 Spare 不是切割 Waste。安装后应把同批次、完整可用的瓷砖留下。具体数量取决于产品、房间和整箱取整后的剩余量。

以下情况更应优先保留：

- 颜色、纹理或图案明显；
- Special order 或产期很短；
- 地暖、检修位置或复杂洁具周围有大量切割；
- 高频使用区域以后可能更适合局部维修；
- 未来很难跨 Shade、Calibre 批次匹配。

在存放箱上写明房间、产品、Supplier、订购日期、Shade 和 Calibre。瓷砖应平放或牢固支撑，避免冻坏、跌落或被误当废料。

## 可直接复制的订购表

每种产品填写一次：

- 房间或表面编号：
- 瓷砖产品和 Supplier code：
- 净贴砖面积：
- 排版和砖缝假设：
- 切割余量及原因：
- 调整后面积：
- 每箱覆盖量：
- 需要的整箱数量：
- 实际到货覆盖量：
- 计划保留的维修备用砖：
- Shade / Calibre / Batch 核对人：
- Installer 最终确认日期：
