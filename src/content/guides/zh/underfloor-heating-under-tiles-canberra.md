电地暖可以提高瓷砖浴室的使用舒适度，但它不是瓷砖排版完成后再随手加进去的配件。它会和基层、电气设计、防水、找平或 Screed、瓷砖胶、瓷砖和伸缩处理共同构成一个地面系统。

这篇文章是给堪培拉业主的规划和交付工作表，不代替已选地暖产品的设计、湿区防水合规路径、瓷砖系统规格，也不代替 ACT 持牌 Electrician 的工作。

## 第一步：画“可加热面积”，不要只写房间面积

先画一张有尺寸的地面图，把每一个固定在地面的物件标出来。地暖供应商通常根据真正能铺设的面积选型，而不是直接用房间总平方米。

图上应标明：

- 浴室柜的占地范围，以及是悬挂还是落地；
- 浴缸、淋浴屏底槽、马桶和 Floor waste；
- 固定柜体、管道和该地暖产品要求排除的区域；
- 开门方向、门槛和相邻地面的过渡；
- Thermostat、供电位置和 Floor sensor 预计路径；
- 瓷砖方向、伸缩缝和材料切换线。

订货前必须对照实际产品手册确认每个排除区。常见加热线不能因为买长了就随意截短；本文核对的 Thermonet 说明明确要求不得剪断或缩短加热线。订货后如果洁具位置变了，不要把多出的线硬塞进小面积，应让 Supplier 和 Electrician 重新检查方案。

## 第二步：先锁定地面完成厚度

从承重结构到瓷砖表面，把每一层和计划厚度列出来。它会影响门底缝、浴缸与浴室柜高度、淋浴入口、地漏、踢脚和相邻房间的高差。

工作表可以包含：

1. 结构地板或现有 Slab；
2. 基层处理、修补或批准的 Underlay；
3. 已选系统需要时的保温板；
4. 加热线或 Mat；
5. 本系统指定的找平层、瓷砖胶或 Screed；
6. 湿区防水层及转角、穿孔和 Waterstop 细节；
7. 瓷砖胶、瓷砖和填缝；
8. 柔性缝和门口过渡。

这份列表不是全部项目都适用的通用施工顺序。不同 Manufacturer 的细节可以不同：有的系统把地暖放在防水层上方，另一些系统可能是地暖在 Screed 内、防水层在 Screed 上。项目团队必须针对真实基层、产品和湿区设计，选择一套相容且有文件支持的层次。

订货前记录门口完成面高度、每个地漏顶高、淋浴找坡方案，以及地暖、找平、防水或瓷砖胶产品的厚度限制。不要把加厚瓷砖胶当成解决高差的临时方案。

## 第三步：开工前把责任分配清楚

写一张简单责任表，不要假设 Tiler、Bathroom renovator 或地暖 Supplier 自然会包含所有受监管工作。

| 决定或记录 | 书面指定的负责方 |
| --- | --- |
| 地暖设计与产品选型 | Supplier / 系统设计方 |
| 电路容量、控制器和受监管电气工程 | ACT 持牌 Electrician |
| 基层和完成面高度评估 | Builder / Tiler / 相关设计方 |
| 湿区合规路径和防水细节 | 相关 Designer、Builder 或 Certifier |
| 各产品相容性 | Manufacturer 和负责施工方 |
| 地面施工期间保护地暖 | 每一个进入区域的工种 |
| 瓷砖排版和伸缩处理 | 按项目规格施工的 Tiler |
| 启用记录和电气证书 | 持牌 Electrician |

ACT Planning 要求固定布线和电气设备由持牌 Electrician 负责。地面封闭前，让该 Electrician 确认电路、Controller、Sensor、必须测试和证书要求，避免瓷砖完成后才发现控制器位置、线路或 Sensor 路径不合适。

## 第四步：把系统层次写成一份定稿

收集真正使用的地暖型号、基层处理、找平或 Screed、防水、瓷砖胶、填缝和瓷砖当前技术文件。只写产品名不够，应在可行时保留文件版本日期和批次。

让每个责任施工方确认：

- 地暖铺设前基层需要什么状态和处理；
- 保温层是必须、允许还是禁止；
- 这套真实系统中防水层的位置；
- 找平、Screed 和瓷砖胶是否明确适用于加热地面；
- 加热线或 Mat 上方的最小与最大覆盖要求；
- 如何保持地漏和坡度，同时不暴露或挤压加热线；
- 周边和中间伸缩缝如何延续到瓷砖完成面；
- 每个阶段使用什么 Primer，以及养护与湿度条件。

ABCB 明确说明，项目不能把不同防水合规路径各取一部分混用。整个地面也应用同样的纪律：不要拼接几张不相关的网络图就假设产品能兼容。

## 第五步：设置三个电气 Hold point

Thermonet 安装说明要求地暖在铺设前、加热线安装完成后、以及地面饰面完成后进行测试。应把它们当成真正的停检点，不要事后凭记忆补写。

每次测试由持牌 Electrician 按已选系统记录所需读数，同时写明房间、产品、型号或序列资料和日期。三组记录放在一起，才能在下一层覆盖原因前发现异常变化。

顺序是：

1. **测试 A（安装前）：**确认到货系统，建立起始读数。
2. **测试 B（铺设后）：**记录已安装读数，并在覆盖前拍下完整加热线或 Mat 布置。
3. **测试 C（贴砖后）：**在启用和交付前确认完成面施工后的读数。

照片要覆盖整个地面、固定排除区、Sensor 路径、Cold tail 路径、地漏，并从永久墙面标注尺寸。只拍一个线圈近景，以后并不能用来判断哪里可以钻孔。

如果读数不在 Manufacturer 允许结果内，立即停止，不要在问题未解决时覆盖。下一步应由 Electrician 和 Supplier 按该产品流程确定。

## 第六步：贴砖期间保护加热线

地暖铺好后，掉落工具、尖锐边、集中踩踏、无计划切割或钻孔都可能损伤线路。在系统被正确覆盖前，对这个房间设置简单进入规则。

- 无关工种和堆放材料不进入地面。
- 只使用地暖及覆盖产品 Manufacturer 允许的保护方法。
- 标明禁止钻孔区，并告知后续安装淋浴屏、浴室柜、Door stop 和 Trim 的人员。
- 不为改善瓷砖排版而移动、交叉、缩短或挤成一团加热线。
- 在工作图上保留地漏、坡度、周边细节和伸缩缝。
- 覆盖前如有修复或批准的排布调整，重新拍照记录。

本文核对的地暖说明要求瓷砖胶完整覆盖，不能用点贴。Tiler 同时必须执行本项目的瓷砖施工规格，包括合适的胶覆盖和伸缩处理。有地暖不代表可以忽略基层、高低差、缝或湿区要求。

在铺地暖前可以用[瓷砖排版、砖缝与伸缩缝检查指南](/zh/guides/tile-layout-grout-movement-joints)解决 Set-out，并用[浴室地砖选择指南](/zh/guides/bathroom-floor-tiles)协调坡度、排水和完成面。

## 第七步：写明最早启用日期

不要启动地暖来加速 Screed、找平层、防水、瓷砖胶或填缝的养护。过早加热会在地面系统未准备好时加入湿度和热应力。

不存在适用于每一套系统的通用等待天数。本文核对的地暖说明有自己的时间要求，而找平、Screed、防水、瓷砖胶和填缝厂家可能规定不同条件。交付前：

1. 收集每一种相关产品的养护与启用要求；
2. 找出最晚或限制最严格的允许启用日期；
3. 把日期写在 Controller 附近或交付表上；
4. 执行地暖或地面产品 Manufacturer 要求的分阶段升温。

如果现场温度、湿度或基层含水率不满足产品条件，只看日历并不能证明地面可以启用。

## 第八步：留下真正有用的交付包

最终业主文件应包含：

- 最终可加热面积图和加热线布置照片；
- 地暖产品、型号、订单和保修资料；
- 测试 A、B 和 C 记录；
- Thermostat、Floor sensor 资料和操作说明；
- 电路编号和适用的 Certificate of Electrical Safety；
- 最终地面层次和防水记录；
- 找平、Screed、瓷砖胶、填缝和防水产品资料；
- 书面最早启用日期和起动说明；
- 瓷砖 Shade、Calibre、Batch label 和维修备用砖；
- 禁止钻孔区和隐蔽管线位置。

这些记录可以让以后的 Electrician 不用猜测就检查系统，也可以避免后续淋浴屏、浴室柜或 Door stop 固定件打到加热线。

## 可以直接用于询价的规划清单

把同一份资料发给地暖 Supplier、Electrician 和 Tiling contractor：

- 有尺寸的房间图和可加热面积图；
- 已选地暖产品和当前安装手册；
- 瓷砖尺寸、表面、排版和砖缝方案；
- 基层类型及已知平整度、湿度或修复问题；
- 拟采用的地面层次、完成面高度、坡度和地漏细节；
- 防水顺序和负责方；
- Thermostat、Sensor、电路和 Cold tail 位置；
- 要求交付的测试、照片、证书和保修资料；
- 洁具排除区与后续钻孔位置；
- 整个地面系统各产品的启用条件。

如果需要结合现场检查瓷砖层次和排版，可以使用 LITA Tiling 的[堪培拉墙地砖服务](/zh/services/floor-and-wall-tiling-canberra)。电气设计、接线、测试和证书仍由相应持牌 Electrician 负责。
